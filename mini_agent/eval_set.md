# Mini Agent 测试用例集 (Eval Set)

本测试集用于检验 `mini_agent` 在极简模式下对不同调研主题的任务拆解、子智能体执行与结果汇聚能力。

## 测试样例列表

| 编号 | 调研主题 | 拆解重点关注项 | 评测合格标准 |
| :--- | :--- | :--- | :--- |
| **Case-1** | 2026年端侧 AI 与 AI PC 的落地现状、主流玩家与核心挑战 | 1. 硬件芯片算力 (NPU/GPU)<br>2. 厂商生态 (微软/苹果/联想)<br>3. 功耗与杀手级场景瓶颈 | 3 个子任务正交不重叠，每个子任务提取至少 2 条事实论据与数值，最终生成结构清晰的研报。 |
| **Case-2** | 全固态电池商业化量产进展：技术路线竞争与关键瓶颈 | 1. 硫化物 vs 氧化物路线<br>2. 宁德时代/丰田量产节点<br>3. 界面阻抗与制造成本瓶颈 | 准确区分不同技术路线，结论包含具体量产年份预期（如2027-2030），来源明确。 |
| **Case-3** | 开源大模型在金融量化风控领域的实操架构与落地困境 | 1. 典型开源底座选型<br>2. 实时行情与因子流对接<br>3. 幻觉与强合规风控边界 | 涵盖技术栈选型与安全合规限制，不可泛泛而谈。 |

## 执行方式

```bash
# 运行默认任务
python mini_agent.py

# 指定主题测试
python mini_agent.py --topic "全固态电池商业化量产进展：技术路线竞争与关键瓶颈"
```
